# Face Educa - Apostilas

Este repositório tem como objetivo armazenar e organizar as apostilas produzidas pelo **Face Educa**, um cursinho popular voltado à preparação de estudantes para o ENEM e vestibulares.

As apostilas são desenvolvidas de forma colaborativa e abrangem diferentes áreas do conhecimento, buscando oferecer material didático gratuito, acessível e de qualidade.

## Estrutura do repositório

Cada disciplina possui sua própria pasta, contendo os arquivos-fonte em LaTeX, imagens e demais recursos necessários para a geração das apostilas.

Exemplo:

```
FaceEduca/
├── Matematica_Basica/
├── Física/
├── Química/
├── Biologia/
├── História/
├── Geografia/
├── Português/
└── ...
```

## Objetivo

Este repositório serve como:

- Repositório central para armazenamento das apostilas;
- Controle de versão dos materiais didáticos;
- Ambiente de colaboração entre os membros responsáveis pela produção do conteúdo;
- Histórico das alterações realizadas em cada disciplina.

## Tecnologias utilizadas

- LaTeX
- Git
- GitHub

## Contribuição

Caso faça parte da equipe de desenvolvimento do material, recomenda-se:

1. Atualizar o repositório antes de iniciar alterações;
2. Realizar commits com mensagens descritivas;
3. Manter os arquivos temporários do LaTeX fora do controle de versão por meio do `.gitignore`.
